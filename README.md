# ระบบสมาชิก ร้านยามุมยาเภสัช (เชื่อม CW Pharma)

## เปิดใช้งาน
ดับเบิลคลิก `YaMumMember.exe` (ไฟล์เดียว วางในโฟลเดอร์ที่เขียนไฟล์ได้ เช่น `D:\member\`) → เบราว์เซอร์เปิดหน้าระบบให้เอง
- หน้าพนักงาน: http://localhost:8088
- หน้าลูกค้า (แท็บเล็ตหน้าร้าน): http://localhost:8088/check

ตั้งแต่ v1.4.0 โปรแกรม**ทำงานเบื้องหลัง ไม่มีหน้าต่างดำ** — มีไอคอนวงกลมสีเขียว "ย" ที่มุมขวาล่าง (ถาดระบบ ถ้าไม่เห็นกดลูกศร ^)
- ดับเบิลคลิกไอคอน = เปิดหน้าพนักงาน
- คลิกขวา = เมนู: เปิดหน้าลูกค้า · เปิดเองเมื่อเปิดเครื่อง (ติ๊กไว้ให้แล้วตั้งแต่เปิดครั้งแรก) · ดูบันทึกการทำงาน · **ปิดระบบสมาชิก**
- ปิดได้จากเมนูไอคอนเท่านั้น (มีถามยืนยัน) จะไม่ดับเพราะเผลอปิดหน้าต่าง
- กด exe ซ้ำตอนเปิดอยู่แล้ว จะแค่เปิดหน้าเว็บให้
- บันทึกการทำงานอยู่ที่โฟลเดอร์ `logs` ข้าง exe
- ตอนเปิดเครื่อง ถ้า SQL Server ยังไม่พร้อม โปรแกรมจะรอได้สูงสุด 3 นาที

ถ้า SQL Server หรือชื่อฐานข้อมูลไม่ใช่ค่าเริ่มต้น (`.\SQLEXPRESS` / `Pmc`) ให้วาง `config.ini` ไว้ข้าง exe

## เชื่อมกับ CW อย่างไร
- อ่านฐานข้อมูล `Pmc` ของ CW บน `.\SQLEXPRESS` โดยตรง — **เขียนลง CW เฉพาะข้อมูลลูกค้า 6 ช่อง** (ดูหัวข้อถัดไป) ส่วนอื่นอ่านอย่างเดียว
- สมาชิก = ลูกค้าในตาราง Customer ของ CW (สมัครสมาชิกทำในโปรแกรม CW ตามปกติ)
- แต้ม = คำนวณจากบิลขายใน CW ที่ผูกรหัสลูกค้า (หักรับคืนสินค้าแล้ว) ตั้งแต่วันที่เริ่มนับแต้ม
- ข้อมูลการแลกแต้ม/ปรับแต้ม/ของรางวัล/ตั้งค่า เก็บในฐานข้อมูลแยก `YaMumMember` (สร้างให้อัตโนมัติ)

## หน้าสมาชิกออนไลน์ — ดูได้แม้ร้านปิด (v1.9.0)
โปรแกรมที่ร้านส่งข้อมูลสมาชิก **เฉพาะคนที่มี PIN** ขึ้น Cloudflare (Worker + ฐานข้อมูล D1) ทุก 5 นาทีที่คอมร้านเปิด
ลูกค้าเข้า https://member.mumyamember.online ได้ตลอด 24 ชม. (เห็นข้อมูล ณ เวลาที่คอมร้านส่งล่าสุด)
คำขอแก้ไขข้อมูล / การเปลี่ยน PIN ที่ลูกค้าทำออนไลน์ เก็บไว้บน Cloudflare แล้วเข้าโปรแกรมร้านเมื่อคอมร้านเปิด

ไฟล์อยู่ในโฟลเดอร์ `cloud/`: `worker.js` (โค้ด Worker) และ `schema.sql` (สร้างตาราง)

ตั้งค่าครั้งเดียว (ใน dash.cloudflare.com):
1. **Storage & Databases → D1 → Create** ชื่อ `yamum-member` → เปิด Console → วางทั้งไฟล์ `schema.sql` → Execute
2. **Workers & Pages → Create → Worker** (Start with Hello World) ชื่อ `yamum-member` → Deploy → **Edit code** → ลบโค้ดเดิม วางทั้งไฟล์ `worker.js` → Deploy
3. Worker → **Settings → Bindings → Add → D1 database**: Variable name `DB` → เลือก `yamum-member`
4. ในโปรแกรมร้าน: ตั้งค่า → หน้าสมาชิกออนไลน์ → **สร้างคีย์ซิงก์** → คัดลอก
5. Worker → **Settings → Variables and Secrets → Add → Type: Secret** ชื่อ `SYNC_KEY` ค่า = คีย์ที่คัดลอก → Deploy
6. Zero Trust → Networks → Tunnels → ลบ Public Hostname `member.mumyamember.online` ของ tunnel เดิม (ถ้ามี)
   แล้ว Worker → **Settings → Domains & Routes → Add → Custom domain** `member.mumyamember.online`
7. ในโปรแกรมร้าน: ใส่ที่อยู่เว็บ `https://member.mumyamember.online` → บันทึก → กด **ซิงก์ตอนนี้** — ขึ้น "ซิงก์สำเร็จล่าสุด" = ใช้ได้

หมายเหตุ
- ข้อมูลบน Cloudflare: ชื่อ (ย่อ) เบอร์โทร แต้ม ประวัติซื้อ/ยา แพ้ยา โรคประจำตัว ที่อยู่ อีเมล ของสมาชิกที่มี PIN — PIN เก็บเป็นค่าแฮชเท่านั้น
- ยกเลิก PIN ที่ร้าน → ข้อมูลคนนั้นถูกลบจากออนไลน์ในการซิงก์ครั้งถัดไป
- หน้าเว็บลูกค้า (check.html) ส่งขึ้นไปพร้อมข้อมูล อัปเดตโปรแกรมแล้วหน้าออนไลน์เปลี่ยนตามเอง ไม่ต้องแก้ Worker
- คีย์ซิงก์รั่ว → กด "สร้างคีย์ใหม่" แล้วใส่ SYNC_KEY ใหม่ใน Cloudflare

## แก้ไขข้อมูลลูกค้า → บันทึกลง CW (v1.8.0)
ช่องที่แก้ได้: เบอร์โทร · อีเมล · ที่อยู่ · วันเกิด · แพ้ยา · โรคประจำตัว (เขียนลง `Customer` ของ CW)
- **พนักงาน**: เปิดสมาชิก → ✏️ แก้ไขข้อมูล → บันทึกลง CW ทันที (แก้แพ้ยามีถามยืนยันอีกครั้ง)
- **ลูกค้า**: หน้าสมาชิก → "แก้ไขข้อมูลของฉัน" → ส่งคำขอ → พนักงานอนุมัติที่แท็บ **คำขอแก้ไข** แล้วจึงบันทึกลง CW
- ทุกการแก้ไขเก็บค่าเดิม/ค่าใหม่/ผู้ทำ/เวลา ในตาราง `CustomerEdit` (ฐานข้อมูล YaMumMember)

## คำนวณแต้ม (v1.8.0)
แท็บ **คำนวณแต้ม** คิดแต้มที่สมาชิกแต่ละคนควรได้ตามอัตราและช่วงวันที่ที่ตั้งใน CW (ยอดสุทธิต่อบิล ปัดลง)
เทียบกับแต้มที่มีใน CW ตอนนี้ — **แสดงผลอย่างเดียว ยังไม่บันทึกลง CW**

## แต้มสะสม (ตั้งแต่ v1.7.0 ใช้แต้มจากโปรแกรม CW)
ตั้งค่า → การสะสมแต้ม → **แหล่งแต้ม**
- **ใช้แต้มจากโปรแกรม CW** (ค่าเริ่มต้น) — ยอดแต้ม = แต้มของลูกค้าใน CW, ประวัติ = แต้มที่ได้/ใช้ในแต่ละบิล CW (หักรับคืนสินค้า)
  - ได้แต้ม/ใช้แต้มแทนเงินสด ทำที่หน้าขาย CW ตามปกติ · ตั้งอัตราแต้มที่โปรแกรม CW
  - ระบบสมาชิก **ปิดปุ่มแลกของรางวัล/ปรับแต้ม** (กันแต้มซ้ำสองที่) · ลูกค้าเห็นแท็บ "ใช้แต้ม" แทน "ของรางวัล"
  - หน้าตั้งค่าแสดงการตั้งค่าแต้มที่อ่านจาก CW และเตือนเมื่อช่วงเวลาสะสมแต้มใกล้หมด/หมดแล้ว
- **คำนวณแต้มเองในระบบสมาชิก** (แบบเดิม) — ทุก N บาท = 1 แต้ม + แลก/ปรับแต้มในระบบสมาชิก
- ระดับสมาชิก (ซิลเวอร์/โกลด์/แพลทินัม) คิดจากยอดซื้อ 12 เดือนเหมือนเดิมทั้งสองแบบ

## หน้าลูกค้า (http://localhost:8088/check)
แท็บเล็ตหน้าร้านมี 2 แท็บ: **เช็คแต้ม** (ใส่เบอร์อย่างเดียว) และ **สมาชิก** (เบอร์ + PIN)
เว็บไซต์มีแค่ **สมาชิก** อย่างเดียว

**พื้นที่สมาชิก** (ตั้งแต่ v1.6.0) — เข้าด้วยเบอร์โทร + PIN แล้วเห็น:
- แต้มคงเหลือ ระดับสมาชิก สิทธิ์ และแถบความคืบหน้าสู่ระดับถัดไป · แบนเนอร์เดือนเกิด
- **ข้อมูลแพ้ยา / โรคประจำตัว** ที่ร้านบันทึกไว้ใน CW (ให้ลูกค้าตรวจและแจ้งถ้าไม่ถูกต้อง)
- **ยาของฉัน** — ยาที่เคยรับ แตะเพื่อดูสรรพคุณ / วิธีใช้ / คำเตือน (จากฉลากยาใน CW)
- **ประวัติการซื้อ** — ทุกบิล ยอดสุทธิ แต้มที่ได้ แตะดูรายการยาในบิล
- **แต้ม** — ที่มาของแต้ม: ได้จากบิลไหน แลกอะไรไป ปรับแต้มเมื่อไร
- **ของรางวัล** — อันไหนแลกได้แล้ว อันไหนขาดอีกกี่แต้ม
- **เปลี่ยน PIN เอง** (ต้องใส่ PIN เดิม) — เครื่องอื่นที่ค้างอยู่จะถูกออกจากระบบ

ความปลอดภัย:
- ประวัติยาและข้อมูลสุขภาพเป็นข้อมูลอ่อนไหวตาม PDPA จึงต้องมี PIN — พนักงานตั้งให้ที่หน้าสมาชิก → "ตั้ง PIN ดูประวัติยา" (ให้ลูกค้ากดเอง)
- ใส่ PIN ผิด 5 ครั้ง ล็อก 30 นาที / ผิด 10 ครั้ง ล็อกจนพนักงานตั้ง PIN ใหม่
- เข้าสู่ระบบแล้วใช้ได้ 15 นาทีนับจากใช้งานล่าสุด (แท็บเล็ตหน้าร้านออกเองใน 90 วินาที) · พนักงานตั้ง PIN ใหม่ = ออกจากระบบทุกเครื่อง

## เว็บไซต์สำหรับลูกค้า (Cloudflare Tunnel) — ตั้งแต่ v1.3.0
โปรแกรมเปิดพอร์ต **http://localhost:8090** สำหรับเว็บไซต์โดยเฉพาะ มีแค่หน้าลูกค้า:
- **พื้นที่สมาชิก** อย่างเดียว — เบอร์โทร + PIN (บนเว็บเช็คแต้มด้วยเบอร์อย่างเดียวไม่ได้ ไม่มีหน้าค้นหายาสาธารณะ)
- หน้าพนักงาน / ข้อมูลสมาชิก / การแลกแต้ม / ตั้งค่า **เข้าจากพอร์ตนี้ไม่ได้**
- จำกัดการลองผิดต่อ IP (ผิด 8 ครั้งใน 30 นาที บล็อก IP นั้น 30 นาที) ไม่ส่งรายละเอียดข้อผิดพลาดออกไป

### ตั้งค่า Cloudflare Tunnel (ทำครั้งเดียว บนคอมที่ร้าน)
1. Cloudflare → **Zero Trust** → Networks → **Tunnels** → Create a tunnel → เลือก **Cloudflared** → ตั้งชื่อ เช่น `yamum-shop`
2. เลือก **Windows** → ทำตามขั้นตอนที่ Cloudflare แสดง: ติดตั้ง cloudflared แล้วรันคำสั่ง `cloudflared.exe service install <token>`
   ใน Command Prompt แบบ **Run as administrator** (token เป็นความลับ ห้ามส่งให้ใคร)
3. หน้า **Public Hostname**: Subdomain เช่น `member` · Domain = โดเมนของร้าน · Service Type **HTTP** · URL **`localhost:8090`**
4. Save → เปิด `https://member.<โดเมน>` จากมือถือ (ตั้งแต่ v1.5.0 ไม่ต้องตั้ง HTTP Host Header — โปรแกรมจัดการเอง)

ถ้าขึ้น "Bad Request - Invalid Hostname" แปลว่าโปรแกรมยังเป็นเวอร์ชันก่อน 1.5.0
ถ้าขึ้นหน้า error ของ Cloudflare (502/1033) แปลว่า YaMumMember หรือ cloudflared ไม่ได้ทำงานอยู่

ต้องเปิดทั้ง YaMumMember.exe และ cloudflared (ติดตั้งเป็น service เปิดเองตอนเปิดเครื่อง) ถ้าคอมที่ร้านปิด เว็บจะใช้ไม่ได้
**ห้ามตั้ง URL เป็น localhost:8088** — นั่นคือหน้าพนักงาน จะเปิดข้อมูลลูกค้าทั้งหมดออกอินเทอร์เน็ต

## ขั้นตอนหน้าร้าน
1. ขายของใน CW โดยเลือกลูกค้า (สแกนบาร์โค้ดสมาชิก) — แต้มเข้าอัตโนมัติ
2. ลูกค้าขอแลก → ในระบบสมาชิก ค้นหา/สแกนบาร์โค้ด → "แลกของรางวัล"
3. ถ้าเป็นส่วนลด แคชเชียร์ใส่ส่วนลดในบิล CW เอง

## อัปเดตอัตโนมัติ
- โปรแกรมตรวจหาเวอร์ชันใหม่ตอนเปิด และทุก 6 ชั่วโมง โดยอ่านไฟล์ `update.json` จาก `UpdateUrl` ใน `config.ini`
- เปิด "อัปเดตอัตโนมัติ" (ค่าเริ่มต้น): ติดตั้งเองตอนเพิ่งเปิดโปรแกรม หรือตอนไม่มีคนใช้งานเกิน 5 นาที
- ปิด: มีแถบแจ้งเตือนด้านบนพร้อมปุ่ม "อัปเดตเลย" / ดูเวอร์ชันและกดตรวจเองได้ที่ ตั้งค่า → อัปเดตโปรแกรม
- ติดตั้งเฉพาะไฟล์ที่เซ็นด้วยกุญแจของร้าน (`keys/update-private.xml`) — ไฟล์ปลอม/เสียจะไม่ถูกติดตั้ง
- ถ้าเวอร์ชันใหม่เปิดไม่ขึ้นภายใน 60 วินาที จะย้อนกลับเวอร์ชันเดิมเอง และไม่ติดตั้งเวอร์ชันนั้นซ้ำอัตโนมัติ
- วาง exe ในโฟลเดอร์ที่เขียนไฟล์ได้ (เช่น `D:\YaMumMember\`) ไม่ใช่ใน `Program Files`

### ปล่อยเวอร์ชันใหม่
1. แก้เลขใน `server.cs` บรรทัด `[assembly: ...AssemblyVersion("1.1.0")]` เป็นเลขที่สูงขึ้น
2. รัน `powershell -ExecutionPolicy Bypass -File publish.ps1 -Notes "มีอะไรใหม่"`
3. อัปโหลด `dist\YaMumMember.exe` และ `dist\update.json` ไปที่ UpdateUrl ชี้อยู่
   (โฟลเดอร์แชร์: ใส่ `-Target \\PC\YaMumUpdate` ให้คัดลอกให้เลย)

**สำรอง `keys\update-private.xml` ไว้ที่ปลอดภัย และห้ามแจกใคร** — ถ้าหาย จะปล่อยอัปเดตที่เครื่องเดิมยอมรับไม่ได้อีก
(ต้องเอา exe ใหม่ไปลงเองทุกเครื่อง 1 ครั้ง)

## ไฟล์
- `server.cs` — โปรแกรมหลัก (แก้แล้วรัน `build.bat` เพื่อคอมไพล์ใหม่)
- `config.ini` — ชื่อ SQL Server / ฐานข้อมูล / พอร์ต
- `wwwroot/` — หน้าเว็บ
